# Golfer’s Journal 2026 Tour Calendar Feed

The Golfer‘s Journal 2026 Tour event calendar is hosted at https://www.golfersjournal.com/tgj-events/.

This repository converts the events page to a calendar feed. The feed is updated on a regular basis.

## Usage

Copy the link of your choice and add to your calendar using the instructions:

### iCalendar (.ics)

```
https://raw.githubusercontent.com/rossta/tgj-calendar-2026/refs/heads/main/feeds/tgj.ics
```

### Google Calendar

- Open Google Calendar in a web browser.
- In the left sidebar, next to "Other calendars", click the + sign.
- Select **From URL** and paste the `.ics` URL you copied.
- Click **Add calendar**. The events will now appear in their Google Calendar, and it will sync periodically for updates.

### Apple Calendar (macOS/iOS):

- On macOS: In the Calendar app, go to **File > New Calendar Subscription**. Paste the `.ics` URL and click **Subscribe**.
- On iOS: Go to **Settings > Calendar > Accounts > Add Account > Other > Add Subscribed Calendar**. Paste the URL and save.

### Microsoft Outlook:

- Open Outlook Calendar in a web browser.
- In the left pane, select **Add calendar**.
- Choose the option to **Subscribe from web** (or "From internet").
- Paste the `.ics` URL and click **Import** or **Save**.

By following these steps, you will have a live, updating view of the events.

### WebCal

Prefer WebCal? Use this URL instead:

```
https://raw.githubusercontent.com/rossta/tgj-calendar-2026/refs/heads/main/feeds/tgj.webcal
```
