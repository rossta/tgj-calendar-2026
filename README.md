# Golfer’s Journal 2026 Tour Calendar Feed

The Golfer‘s Journal 2026 Tour event calendar is hosted at https://www.golfersjournal.com/tgj-events/.

This repository converts the events page to a calendar feed. The feed is updated on a regular basis.

## Usage

Copy the link of your choice and add to your calendar.

- Google (ics): https://raw.githubusercontent.com/rossta/tgj-calendar-2026/refs/heads/main/feeds/tgj.ics
- Apple (webcal): https://raw.githubusercontent.com/rossta/tgj-calendar-2026/refs/heads/main/feeds/tgj.webcal
